# Правила разработки IronCore

## Git Workflow
- **Ветки:** Вся разработка ведется в отдельных ветках `feature/*`.
- **Push:** Агент имеет право автоматически пушить промежуточный код в feature-ветки (в режиме YOLO).
- **Merge:** Агенту СТРОГО ЗАПРЕЩЕНО выполнять команду `git merge` или любые действия по слиянию веток в `main`.
- **PR:** Все Pull Request и слияния в `main` выполняет ТОЛЬКО пользователь вручную.

## Engineering Standards
- Версия Minecraft: 1.20.1
- Загрузчик: Forge (стандартный, не NeoForge)
- Архитектура: Все данные костюма хранятся в SuitCapability (Player-side).
