# 🔴 IronCore

![Minecraft Version](https://img.shields.io/badge/Minecraft-1.20.1-brightgreen)
![Loader](https://img.shields.io/badge/Loader-Forge-blue)
![Status](https://img.shields.io/badge/Status-v1.2-green)

**IronCore** — хардкорный инженерный мод для Minecraft 1.20.1, вдохновлённый историей Железного Человека. Вы — инженер, который строит сложную машину: костюм питается от вживлённого реактора-импланта, требует энергии, технического обслуживания и имеет реальные последствия от использования.

---

## ⚠️ Совместимость

Мод **несовместим с OptiFine.** OptiFine переопределяет конвейер рендеринга Minecraft и конфликтует с **GeckoLib** (3D-модели брони) и событиями рендера Forge (HUD, наклон модели в полёте) — костюм и интерфейс будут отображаться некорректно.

Если нужны производительность и шейдеры, используйте **форки Sodium для Forge** вместо OptiFine:
- **Embeddium** (или более старый **Rubidium**) — оптимизация рендеринга;
- **Oculus** — поддержка шейдеров.

Это рекомендованная и совместимая с модами замена OptiFine.

## 🦾 Костюмы

| Тир | Название | Особенности |
|-----|----------|-------------|
| **Mk1** | Escape Suit | Защита, огнемёт. Полёт недоступен — нужен реактор-имплант |
| **Mk2** | Prototype | Первый летающий костюм. Уязвим к обледенению выше 170 блоков и перегреву при форсаже |
| **Mk3** | Golden Avenger | Золото-Титановый сплав. Иммунитет к обледенению, репульсорные лазеры, турбо-режим |

Все тиры требуют вживлённого **реактора-импланта** для активации систем.

---

## 🔋 Энергетика

- **Реактор-имплант** — главный источник питания. Скрафтите предмет **Палладиевый реактор** и активируйте его (ПКМ) — запустится хирургическая процедура вживления. После операции реактор встроен в тело игрока и питает костюм; энергия хранится в самом импланте.
- **Palladium Core** — расходник для дозаправки импланта. Использование восполняет энергию реактора и оставляет **отработанный стержень** (токсичен — не носите его с собой).
- **Arc Reactor Core** — стационарный блок-маяк. Пассивно заряжает имплант игроков в радиусе. Требует FE-питания (совместим с другими тех-модами).

---

## ☢️ Хардкорные механики

**Палладиевое отравление** — вживлённый реактор-имплант постепенно отравляет кровь. Скорость нарастания зависит от режима:

| Ситуация | Скорость до 100% |
|----------|-----------------|
| Boost-полёт с имплантом | ~4.6 ч |
| Крейсерский полёт | ~14 ч |
| На земле в костюме | ~28 ч |
| Без костюма (дормантный имплант) | ~1400 ч |

Следите за шкалой TOXICITY в HUD. Пейте **Хлорофилловый сок** для снижения токсичности.

**Термодинамика** — костюмы нагреваются в полёте, охлаждаются в воде или холодном климате.

**Обледенение** — на Mk2 опасно подниматься выше 170 блоков: системы могут отказать.

## 🛤 Прогрессия

1. **Добыча** — найдите **Палладий** и **Титан** в глубоких пещерах.
2. **Материалы** — выплавьте слитки, создайте **Золото-Титановый сплав** в Сплав-печи.
3. **Реактор** — скрафтите **Палладиевый реактор** и вживите его (ПКМ → хирургическая процедура). Теперь имплант питает костюм.
4. **Костюм** — соберите любой тир на обычном верстаке и наденьте — системы активируются от импланта.
5. **База** — постройте **Arc Reactor Core** для пассивной подзарядки импланта не отходя от базы.

## ⚙️ Управление

| Клавиша | Действие |
|---------|----------|
| `Ctrl` (двойное нажатие, на земле) | Форсажный взлёт |
| `Ctrl` (в полёте) | Ускорение / Boost |
| `Space` / `Shift` | Подъём / спуск |
| `V` | Открыть/закрыть маску (Mk2/Mk3) |
| `R` | Переключить авто-турбо (Mk3) |
| `Z` | Оружие (огнемёт Mk1/Mk2, репульсоры Mk3) |

## 🏭 Блоки и машины

| Блок | Назначение |
|------|-----------|
| Сплав-печь | Создание Gold-Titanium Alloy и других сплавов |
| Suit Station | Слот нагрудника — станция обслуживания костюма (база для системы модулей) |
| Arc Reactor Core | Маяк пассивной зарядки импланта и радар угроз |

## 🏗 Архитектура

```
src/main/java/com/pavel/ironcore/
├── flight/
│   ├── FlightConfig.java      — константы физики по тирам (MK2/MK3)
│   └── FlightPhysics.java     — чистые функции расчёта полёта
├── item/
│   ├── BaseSuitItem.java      — общий тиковый цикл (inventoryTick)
│   ├── Mk2FrameItem.java      — нагрев, обледенение
│   └── Mk3FrameItem.java      — + турбо, репульсоры
├── capability/
│   └── SuitCapability.java    — все состояния костюма (NBT)
├── block/entity/
│   ├── AbstractMachineBlockEntity.java
│   ├── AbstractEnergyMachineBlockEntity.java
│   └── ArcReactorCoreBlockEntity.java
├── network/
│   └── ModMessages.java       — Simple Channel, пакеты клиент↔сервер
└── client/
    ├── SuitHUD.java            — HUD: энергия, тепло, иней, токсичность, скорость
    └── KeyBindings.java        — регистрация клавиш
```

Клиент авторитативен по физике (`setDeltaMovement`), сервер — по энергии, урону и эффектам. Синхронизация через `PacketSyncSuitData`.

## 🔧 Сборка

### Требования
- **Java 17** (Eclipse Temurin или OpenJDK)
- **Git**

**Linux / macOS:**
```bash
git clone https://github.com/avelNet/IronCore.git
cd IronCore

# Первая сборка скачивает Minecraft + Forge (~600 MB)
./gradlew build
```

**Windows (PowerShell / CMD):**
```bat
git clone https://github.com/avelNet/IronCore.git
cd IronCore

REM На Windows используется gradlew.bat
gradlew.bat build
```

Готовый `.jar` — в `build/libs/`.

### Конфигурация окружения

**Linux / macOS:**
```bash
cp .env.example .env
```

**Windows:**
```bat
copy .env.example .env
```

### Docker (воспроизводимая сборка, кроссплатформенно)

Требуется установленный **Docker Desktop** (Windows/macOS) или **Docker Engine** (Linux). Команда одинакова на всех ОС:

```bash
docker compose up --build
# Артефакт появится в ./build/libs/
```

### Установка в Minecraft

Скопируйте `build/libs/ironcore-1.2.jar` в папку `mods` клиента с Forge 47.2.0 и GeckoLib 4.4.9:

| ОС | Путь к папке mods |
|----|-------------------|
| Windows | `%APPDATA%\.minecraft\mods` |
| Linux | `~/.minecraft/mods` |
| macOS | `~/Library/Application Support/minecraft/mods` |

### Статический анализ

```bash
./gradlew checkstyleMain      # Linux / macOS
gradlew.bat checkstyleMain    # Windows
# Отчёт: build/reports/checkstyle/main.html
```
