## 1. Цель сервиса / утилиты

**IronCore** — это модификация для Minecraft 1.20.1 (Forge), реализующая полноценную инженерно-техническую систему на базе вымышленного экзоскелета.  
Ключевая ценность: динамическая симуляция физики полёта, энергетики реактора и деградации систем (перегрев, обледенение, палладиевое отравление) с разделением логики по слоям: клиент (физика, HUD) / сервер (урон, эффекты, частицы) / capability-хранилище состояния.  
Проект демонстрирует применение чистой архитектуры (отдельный `FlightPhysics`/`FlightConfig`, абстрактные базовые классы машин), event-driven подхода Forge, синхронизации по сети через кастомные пакеты и автоматической генерации контента через Datagen.

**Тип интерфейса:** встроенный игровой HUD (overlay) + инвентарные экраны (Screens/Menus), REST-API отсутствует — управление через клиентские события Minecraft.

```
Player Input ──▶ BaseSuitItem.inventoryTick()
                    │
                    ├── isLocalPlayer? ──▶ applyClientPhysics()
                    │                          │
                    │                     SuitCapability.get()
                    │                          │
                    │                    ┌─────▼──────┐
                    │                    │isBoosting? │
                    │                    └─────┬──────┘
                    │                     yes  │  no
                    │              ┌───────────┘  └────────────────┐
                    │         FlightPhysics              FlightPhysics
                    │         .computeBoostVelocity()   .computeHoverVelocity()
                    │              │                           │
                    └──────────────▼───────────────────────────▼
                            player.setDeltaMovement(newVelocity)
                                          │
                                   Vanilla Player.travel()

```
